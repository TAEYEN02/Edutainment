# 영유아를 위한 에듀테인먼트 앱 개발 (Edutainment App)
- 개요 : 2020년부터 시작된 코로나 팬데믹으로 인해 아이들의 언어 발달이 지연되고 있습니다. 그들에게 조금이나마 도움이 되고자, 발음교정과 간단한 게임을 통해 학습을 동시에 할 수 있는 앱을 만들었습니다.
- 도구 : 안드로이드 스튜디오, SQLite, Firebase
- 언어 : 자바
- 주요 기능 : 발음 평가 기능 -> google speech api 사용
